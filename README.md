# wireshark-basic-lab
A hands-on network traffic analysis project using Wireshark to capture and inspect live packets. The project demonstrates understanding of DNS resolution, IP addressing, and protocol-based communication (TCP/IP, HTTP/HTTPS) during real-time web browsing activity


# Wireshark Basic Network Traffic Analysis 🧪

## 📌 Overview
This project demonstrates a simple network traffic capture using Wireshark. The goal is to understand how data moves across a network and how to identify different types of packets such as DNS requests, HTTP/HTTPS traffic, and IP communications.

---

## 🎯 Objectives
- Install and configure Wireshark
- Capture live network traffic
- Generate web traffic using a browser
- Analyze DNS and IP packets
- Understand basic network communication

---

## 🧰 Tools Used
- Wireshark
- Internet browser (Chrome/Firefox)
- Windows/Linux/Mac OS

---

 Steps Followed

 1. Installation
Installed Wireshark and required Npcap driver.

 2. Packet Capture
- Opened Wireshark
- Selected active network interface (Wi-Fi)
- Started live capture

 3. Traffic Generation
Visited websites such as:
- google.com
- youtube.com

4. Filtering Packets
Used filters:
dns
http


### 5. Analysis
- Observed DNS queries resolving domain names
- Identified source and destination IP addresses
- Viewed protocol-based traffic flow
